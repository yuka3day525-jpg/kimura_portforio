TRAINING PROJECT / 04

Black Poodle

黒プードルをテーマにした参加型Webサイト

黒プードルの魅力を紹介するサイトを、PHP・MySQLを使って機能を拡張し、写真投稿ギャラリー、クイズ、犬のニュース表示など、閲覧者が楽しめる仕組みを実装しました。

  • PHP
  • MySQL
  • JavaScript
  • jQuery
  • RSS

概要 機能の詳細 開発の工夫 生成AI活用 今後の改善

01 / OVERVIEW

制作背景・作品概要

黒プードルをテーマに、様々な機能を楽しめるWebサイトを制作しました。当初の紹介ページに加え、PHP・MySQLの学習内容を活用し、訪問者が参加できる機能を追加しました。

掲示板機能、回答を保持できるクイズ、RSSによるニュース表示を実装し、静的な紹介サイトから、データの登録・取得・表示ができるサイトへ発展させました。

制作区分
自主制作
開発言語・データベース
HTML / CSS / PHP / MySQL
使用技術
jQuery / SESSION / Cookie / RSS

02 / FEATURE DETAILS

機能の詳細

写真投稿・クイズ・ニュース配信などを、実際の画面とあわせて紹介します。

FEATURE 01

ナビゲーションとページ紹介を意識したデザイン

黒プードルをテーマに、写真や配色、余白の使い方を意識しながら、 サイト全体の見た目に統一感を持たせました。 上部にはナビゲーションメニューを設け、 各ページへ移動しやすい構成にしています。

また、トップページには各コンテンツの紹介を縦に配置し、 サイトをスクロールしながら 「どんなページがあるか」を自然に把握できるようにしました。 写真や見出しを使い、視覚的にも楽しめる構成を意識しています。

  • 各ページへ移動できるナビゲーションメニュー
  • トップページに各コンテンツの紹介を配置
  • 写真・配色・余白を意識したデザイン
  • サイト全体で統一感のあるレイアウト
  • スマートフォンにも対応したレスポンシブデザイン

FEATURE 02

写真投稿・確認画面・画像の一時保存

自慢の「うちの子」を紹介できる写真投稿機能です。 写真と入力内容を受け取り、確認画面で投稿内容を確認した後、 確定したデータをMySQLへ登録します。

確認画面へ移動する際は、入力情報をSESSIONで保持し、 アップロードされた画像は一時的に保存しています。 投稿を確定した段階で本登録することで、 確認・修正を行ってから投稿できる流れにしました。

  • 写真付き投稿フォーム
  • 入力内容の確認画面とバリデーション
  • SESSIONによる入力情報の保持
  • 確認中の画像ファイルの一時保存
  • 投稿確定後の画像・データ登録
  • MySQLへの投稿情報保存

FEATURE 03

投稿ギャラリー・日付別表示・投稿回数の制限

投稿された写真や情報をMySQLから取得し、 ギャラリー形式で一覧表示します。 また、投稿された日付ごとにボタンを用意し、 見たい日付を選んで投稿内容を切り替えて確認できるようにしました。

さらにCookieを利用して、 同じブラウザからの投稿を1日1回に制限しています。 すでに投稿済みの場合は、その旨を画面上に表示する仕組みです。

  • MySQLからの投稿データ取得・表示
  • 日付ごとのボタンによる投稿一覧の切り替え
  • 日付別の投稿内容表示
  • Cookieを利用した1日1回の投稿制限
  • 投稿済みの場合の案内表示

FEATURE 04

PHP・SESSIONを使ったクイズ機能

黒プードルに関する問題に1問ずつ回答していくクイズ機能を実装しました。 各問題の回答内容はSESSIONに保存し、 ページを移動しても選択した回答が保持されるようにしています。

前の問題に戻って回答を変更することもでき、 すべての回答後には確認画面を表示してから結果画面へ進む構成です。 単純に問題を表示するだけでなく、 複数ページをまたいだ入力内容の保持や画面遷移を学ぶことを意識して制作しました。

  • 1問ずつ回答するクイズ形式
  • SESSIONによる回答内容の保持
  • 前の問題に戻って回答を修正
  • 回答内容の確認画面
  • 回答結果の判定・表示
  • 複数ページ間での状態管理

FEATURE 05

RSSを利用した外部ニュースの取得・表示

犬に関する最新情報をサイト内でも確認できるよう、 外部サイトのRSSを取得してニュース一覧を表示する機能を実装しました。 PHPでRSSデータを読み込み、 記事タイトルや公開情報など必要なデータを取り出して表示しています。

取得した記事は一覧形式で確認でき、 気になるニュースを選択すると元の記事へ移動できます。 自分で登録したデータだけでなく、 外部から取得した情報をWebサイト上に組み込む処理を学ぶために実装しました。

  • RSSから犬に関する記事情報を取得
  • 取得したデータをPHPで処理
  • 新着記事を一覧形式で表示
  • 記事タイトルや公開情報の表示
  • 元のニュース記事へのリンク
  • 外部データをサイト内コンテンツとして活用

03 / DEVELOPMENT

開発で工夫したこと

入力確認からDB保存までの流れ

フォームで受け取った情報をSESSIONで保持し、確認画面を通してから画像と投稿内容をMySQLに登録する構成にしました。

投稿回数を制御する仕組み

Cookieを使って同一ブラウザからの投稿回数を制限し、投稿済みの場合には案内を表示できるようにしました。

投稿機能のセキュリティ対策

投稿フォームでは入力値の確認やエスケープ処理を行い、 不正な入力やXSSを防ぐことを意識して実装しました。 また、データベースへの登録にはPDOのプリペアドステートメントを使用し、 SQLインジェクション対策を行っています。

外部RSSとの連携

ニュースを手入力するのではなく、RSSから取得して表示することで、外部情報をサイト内に取り込む仕組みを学びました。

生成AIの活用

制作過程での生成AIの利用について紹介します。

開発過程のAI活用
