Harry Potter

呪文を題材にした英語学習Webアプリ

Harry Potter APIから取得した呪文の英語説明文を日本語に翻訳し、 英文から抽出した単語の意味と合わせて学習できるWebアプリです。 学習した呪文は履歴として保存し、Excel形式でダウンロードできます。

01 / OVERVIEW

制作背景・作品概要

ハリー・ポッターの呪文を題材に、興味のある作品を通じて 英語を楽しく学べるWebアプリをFlaskで制作しました。

Harry Potter APIから呪文の英語説明文を取得し、 Gemini APIで日本語に翻訳して表示します。 さらに英文から英単語を抽出し、辞書APIを利用して意味を確認できます。 学習した内容はSQLiteに保存でき、履歴の閲覧やExcelへの出力にも対応しています。

制作区分
自主制作
開発言語・フレームワーク
Python / Flask / JavaScript / SQLite
データ処理・外部API
Requests / NLTK / Gemini API / openpyxl / Harry Potter API / 辞書API

02 / FEATURE DETAILS

機能の詳細

スクリーンショットとともに、呪文の取得から学習履歴の保存・出力までを紹介します。

FEATURE 01

呪文情報の取得・翻訳・英単語学習

Harry Potter APIから呪文名と英語の説明文を取得し、 ランダムに選んだ呪文を表示します。 取得した英語説明文はGemini APIを利用して日本語へ翻訳し、 英文と日本語訳を見比べながら内容を確認できるようにしました。

さらに、英語説明文から正規表現を使って英単語を抽出し、 重複する単語や短い単語、一部の基本語を除外しています。 NLTKを利用して動詞・名詞・形容詞の原形候補を作成し、 辞書APIから日本語の意味を取得することで、 呪文を題材に英単語も学習できる構成にしました。

  • Harry Potter APIから呪文情報を取得
  • ランダムに一つの呪文を選択して表示
  • Gemini APIによる英語説明文の日本語翻訳
  • 正規表現による英単語の抽出・不要語の除外
  • NLTKによる単語の原形化
  • 辞書APIを利用した日本語の意味の取得
  • 英文・日本語訳・英単語をまとめて学習

FEATURE 02

学習履歴の保存・閲覧

ユーザー名とともに、呪文名・英文・日本語訳・単語の意味をSQLiteに保存します。 保存した呪文は履歴画面から確認できます。

  • ユーザー名と呪文情報を保存
  • 登録日時を記録
  • 保存した履歴を一覧表示

FEATURE 03

学習履歴のExcel出力

履歴に保存した呪文名・英文・日本語訳・単語の意味をopenpyxlでExcelファイルにまとめ、 ダウンロードできるようにしました。

  • SQLiteから履歴データを取得
  • openpyxlでExcelファイルを生成
  • 学習履歴をExcel形式でダウンロード

03 / VIDEO

操作デモ動画

無料枠のGemini APIを利用しているため、 利用状況によっては翻訳処理に時間がかかったり、 一時的に正常に動作しない場合があります。 その場合にも実際の操作手順や動作を確認できるよう、 アプリの操作動画を掲載しています。

収録内容：呪文取得 → 日本語訳・単語の確認 → 履歴保存 → Excel出力。

04 / DEVELOPMENT

開発で工夫したこと

複数の外部APIを組み合わせた構成

呪文情報の取得、Gemini APIによる翻訳、辞書APIによる単語検索を組み合わせ、 一つの画面で英語学習を進められるようにしました。

英単語の前処理

正規表現で取り出した単語の重複や基本語を除外し、 NLTKで原形化してから辞書APIで調べる処理を実装しました。

JavaScriptの活用

フロントエンドにはJavaScriptも使用し、 Python・Flaskによるサーバー側の処理と組み合わせてWebアプリの画面を構成しました。

Excel形式での出力

openpyxlを利用し、保存した学習履歴をExcelファイルとして生成し、 ダウンロードできるようにしました。

05 / GENERATIVE AI

生成AIの活用

アプリ内の翻訳機能と、開発過程での生成AI活用を分けて紹介します。

アプリ内のAI機能

Gemini APIによる日本語翻訳

Harry Potter APIから取得した英語説明文をGemini APIに渡し、 日本語訳を生成して原文とあわせて表示しています。

開発過程のAI活用

実装方法の検討・エラー調査の補助

生成AIを、実装方法の検討やエラー原因の整理を行うための補助として活用しました。 提案された内容は自分で処理を確認し、実際の動作を見ながら修正して開発を進めました。

06 / NEXT STEPS

今後の改善点

今後は、外部APIやGemini APIの取得失敗時にも利用者が状況を把握できるよう、 エラーメッセージや例外処理をより分かりやすくしたいと考えています。

また、学習履歴の検索や絞り込みなどを追加し、 保存した内容をより振り返りやすい英語学習アプリへ改善していきたいです。
