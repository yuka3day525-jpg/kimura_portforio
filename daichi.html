商品を探す・カートに入れる・購入手続きを進める流れに加え、顧客や商品を扱う管理者画面も制作した、自然派スキンケア商品を取り扱うECサイトです。

01 / OVERVIEW

制作背景・作品概要

PHPとMySQLを活用し、商品を選ぶ利用者側と、商品・顧客を管理する運営側の両方を備えたECサイトを制作しました。

商品一覧・詳細表示、検索やカテゴリによる絞り込み、カート、会員ログインに加え、管理者専用ページでのデータ管理にも取り組みました。画面の演出にはjQueryも利用しています。

HTML / CSS / PHP / MySQL
使用技術
jQuery / SESSION / SCSS /

02 / FEATURE DETAILS

機能の詳細

利用者向け画面と管理者向け画面に分けて、主な機能を紹介します。

FEATURE 01

商品一覧・検索・在庫表示

MySQLに登録した商品情報をPHPで取得し、 商品一覧に表示しています。 商品名によるキーワード検索やカテゴリでの絞り込み、 価格の安い順・高い順、新着順での並び替えに対応しています。

また、在庫数に応じて「残りわずか」などの表示を出し、 商品の在庫状況が一覧から分かるようにしました。 各商品には詳細ページを用意し、 商品説明や価格、在庫状況などをより詳しく確認できます。

  • 商品名によるキーワード検索
  • カテゴリでの絞り込み
  • 価格順・新着順の並び替え
  • 在庫数に応じた在庫状況の表示
  • 商品詳細ページでの詳細情報表示

FEATURE 02

カート・購入処理・在庫管理

商品をカートに追加し、購入手続きまで進められるようにしました。 カート情報はPHPのセッションで保持し、 ページを移動しても選択した商品や数量が残る構成です。

注文確定時には商品の販売状態と在庫数を再確認し、 カート追加後に販売停止となった商品や、 在庫切れになった商品は注文できないようにしています。 また、注文が完了すると購入数量に応じて在庫数を減らします。

  • 商品のカート追加・数量管理
  • セッションによるカート内容の保持
  • 購入時の販売状態・在庫数の再確認
  • 販売停止・在庫切れ商品の注文防止
  • 注文完了時の在庫数更新

FEATURE 03

購入手続き・注文情報の登録

カート内容を確認したうえで購入手続きへ進み、 注文確定時に購入商品や合計金額、 配送先などの注文情報をデータベースへ登録する処理を実装しました。

フォーム送信時にはCSRF対策を行い、 不正なリクエストによる注文処理を防ぐ構成にしています。 注文が正常に確定した後は、 注文内容とあわせて購入時のお客様情報も登録されます。

  • 購入内容・合計金額の確認
  • CSRF対策による不正リクエスト防止
  • 注文確定後の注文情報登録
  • 購入時のお客様情報の保存
  • 注文商品・数量・価格のデータベース保存

FEATURE 04

会員登録・ログイン・権限管理

新規会員登録とログイン機能を実装し、 セッションを利用してログイン状態を管理しています。 登録時のパスワードはハッシュ化して保存し、 平文のままデータベースへ保存しない構成にしています。 また、利用者と管理者を区別し、 管理者用ページは管理者以外がアクセスできないよう制限しています。

  • 新規会員登録・会員ログイン・ログアウト
  • パスワードのハッシュ化保存
  • セッションによるログイン状態の管理
  • 利用者・管理者の権限分け
  • 管理者専用ページのアクセス制限

FEATURE 05

管理者向け商品・顧客データ管理

管理者専用画面から、商品情報や顧客情報を確認・管理できるようにしました。 商品については、一覧表示や検索・カテゴリ絞り込みに加えて、 新規追加、内容の変更・更新、販売停止にも対応しています。 また、顧客一覧から各顧客の詳細情報を確認できる構成にしています。

  • 管理者認証による閲覧制限
  • 商品の新規追加
  • 商品情報の編集・更新
  • 商品の販売停止・再販売
  • 商品一覧・検索・カテゴリ絞り込み
  • 顧客一覧・顧客詳細の確認

03 / DEVELOPMENT

開発で工夫したこと

検索・絞り込み処理の実装

商品検索やカテゴリによる絞り込みでは、 PDOのプリペアドステートメントとパラメータバインドを利用し、 入力された条件に応じて必要な商品だけを取得する処理を実装しました。 あわせて、新着順・価格の安い順・高い順で並び替えられるようにし、 商品を探しやすい構成にしています。

在庫・販売状態を考慮した商品管理

商品詳細では在庫数に応じて選択できる購入数量を制御し、 在庫切れの商品はカートに追加できないようにしました。 また、注文確定時にも在庫数と販売状態を再確認し、 カート追加後に売り切れや販売停止となった商品が そのまま注文されないようにしています。

jQuery・SCSSを用いたUI設計

jQueryと背景画像切り替え用プラグインを利用して スライドショーを実装しました。 また、SCSSを用いてレイアウトや装飾を管理し、 ナビゲーションや商品表示を含めて、 PC・スマートフォンのどちらでも見やすい画面になるよう調整しています。

セキュリティを意識した管理・フォーム処理

管理者専用ページではセッションによる権限確認を行い、 管理者以外のアクセスを制限しています。 また、商品登録・更新・購入処理などではCSRF対策を行い、 PDOのプリペアドステートメントによるSQLインジェクション対策、 htmlspecialchars()によるXSS対策、 パスワードのハッシュ化などを実装しました。

05 / NEXT STEPS

今後の改善点

今後はJavaScriptを活用し、 商品の絞り込みやカート操作、数量変更などをより動的に行えるようにして、 ページ遷移や再読み込みを減らしたいと考えています。 操作結果がその場で分かるようにすることで、 より使いやすいECサイトに改善したいです。

また、入力エラーや在庫切れ、販売停止などの状態についても、 JavaScriptを用いて分かりやすく表示し、 利用者が迷わず操作できる画面づくりを進めたいと考えています。
